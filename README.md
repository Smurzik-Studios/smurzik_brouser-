# 🌌 Smurzik Browser v1.0

**Мульти-поиск браузер с интерфейсом «Северное Сияние»**

Smurzik Browser — это современный браузер на базе Electron, который одновременно ищет информацию в Google, Яндекс, Bing и DuckDuckGo, отображая результаты в удобном сплит-вью интерфейсе.

## ✨ Особенности

### 🌈 Уникальный интерфейс «Северное Сияние»
- Яркий анимированный градиент с бирюзовыми, фиолетовыми и зелёными оттенками
- Непрерывная анимация переливания цветов
- Полупрозрачные элементы с эффектом glassmorphism

### 🔍 Мульти-поиск
- Одновременный поиск в **4 поисковых системах**: Google, Яндекс, Bing, DuckDuckGo
- Сплит-вью интерфейс: одна основная панель + три дополнительных
- Полные карточки с изображениями и описаниями
- Возможность закрыть любую панель поиска

### 📑 Система вкладок
- Вкладки расположены снизу
- Перетаскивание для изменения порядка
- Восстановление вкладок при перезапуске
- Индикатор режима инкогнито

### 🔖 Боковая панель
- **Закладки** с папками и организацией
- **История** просмотров с поиском
- **Менеджер загрузок**

### 🛡️ Приватность и безопасность
- Режим инкогнито с индикатором
- Встроенный блокировщик рекламы и трекеров
- Полная история с датами

### 📸 Дополнительные функции
- Скриншот страницы (видимая область, вся страница, выбор области)
- Читательский режим для статей
- Перевод страниц на любые языки
- Горячие клавиши (Ctrl+T, Ctrl+W, Ctrl+L, Ctrl+D, Ctrl+H, Ctrl+J, F11)
- Страница «Новая вкладка» с часами, поиском и быстрыми ссылками
